# Fulbo

Fulbo is a football-field booking platform with a React/Vite frontend and a NestJS/Prisma backend.

## Repository map

- `frontend/` — web client and UI flows.
- `backend/` — REST API, authentication, and database schema.
- `docs/` — architecture, active plans, decisions, and operational guides.
- `graphify-out/` — generated codebase graph; do not edit manually.

## Getting started

Read [the development guide](docs/guides/development.md), then use the component-specific README in `frontend/` or `backend/`.

## Project status

The frontend has the principal user and manager journeys implemented. The backend currently contains the platform foundation, Prisma schema, and authentication module; the remaining domain modules are planned in [the backend plan](docs/plans/current/backend.md).
